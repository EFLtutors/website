# EFL Tutors website draft

The five-page static website is saved in this repository:

- `index.html` — homepage with your two founder photos
- `booster-classes.html` — £75/month classes, timetable, filters and FAQs
- `tutoring.html` — 1:1 tuition, subjects, rates and FAQs
- `schools-partners.html` — prospective partnership information and school enquiry preview
- `our-approach.html` — teaching philosophy

Keep `assets/`, `styles.css` and `script.js` with these pages. Open `index.html`, or serve this directory using `python -m http.server 8000`.

`preview.html` is a complete single-file review copy with all five pages, both original founder photos and styling embedded. It can be opened by itself. `website-preview.zip` contains that file as `OPEN-WEBSITE.html`.

The website is a draft. Enquiry forms validate locally but send nothing. Confirm current class availability, payment/cancellation terms and business policies before launch. No deployment has been performed.
